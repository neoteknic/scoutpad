ScoutPad 1.1.0 fournit une application Android autonome et une application Windows x64 portable pour piloter un Moorebot Scout avec une manette et afficher sa camera ROS.

## Telechargements

- `ScoutPad-Android-1.1.0.apk` : installer sur le telephone ou la console Android. Mise a jour compatible avec l'APK debug precedemment installee sur cette machine.
- `ScoutPad-Windows-x64.zip` : extraire puis ouvrir `ScoutPad.exe`. Le serveur ROS est inclus. Le lanceur ouvre le navigateur et reste dans la zone de notification pour permettre un arret propre. Windows 10/11 x64 avec .NET Framework 4.8.
- `SHA256SUMS.txt` : sommes de controle des deux fichiers.

## Corrections

- Arret des joysticks prioritaire, sans attendre l'intervalle d'envoi.
- Actions A/B preservees dans leur propre file et rejet des commandes anciennes apres un arret.
- Appuis courts de manette Android transmis comme evenements et detection reelle des peripheriques.
- Axes neutralises a la suspension ; reprise apres recentrage des sticks.
- Reconnexion du reseau et de la video avec temporisation progressive.
- Duree de sortie de base separee du watchdog de pilotage.
- Boucles Go fermees a l'arret et recuperation du processus WebView.
- Vitesses d'avance, de translation et de rotation independantes.
- Affichage de l'age de la derniere image et du temps de reponse des commandes.
- Fonctions indisponibles masquees dans les applications natives.

## Commandes

A : sortie de base / annulation du retour. B : retour base. Start : armer/desarmer. LB : video. RB : plein ecran.
Stick gauche : avance/recul et rotation. Stick droit horizontal : translation.
Le controle demarre desarme. Le PC ou l'appareil Android doit etre sur le meme reseau que le robot ; IP par defaut `192.168.0.142`.

## Verification

Tests JavaScript et Go, analyse statique Go, lint Android, verification de l'interface sur quatre formats d'ecran avec API simulees, et demarrage/arret du paquet Windows portable. Aucun essai physique du robot n'a ete effectue pour cette version.
